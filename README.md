# 2048 · 无限撤销版

一个**单文件实现**的现代 2048 小游戏：HTML + CSS + JS 全部内嵌于一个 `index.html`，零依赖、零构建，双击即玩，同时支持电脑与手机。

## ✨ 特性

- **无限撤销** —— 每一次有效移动都会保存完整快照，可一路撤回到开局；撤销按钮上实时显示可撤销步数
- **多端操作** —— 电脑：方向键 / WASD / 鼠标拖动棋盘 / `Ctrl+Z`；手机：手指滑动
- **正确的得分机制** —— 得分 = 合并后的数值（2+2→4 得 4 分，4+4→8 得 8 分，8+8→16 得 16 分，依此类推）
- **新方块概率** —— 每次有效移动后随机生成一个新方块：90% 为 2，10% 为 4
- **流畅动画** —— 滑动、合并弹出、新方块出现、得分飘字
- **最高分记录** —— 通过 `localStorage` 持久化，撤销不会回退最高分
- **响应式 + 强兼容** —— 适配手机 / 平板 / 桌面；对旧内核（旧版 WebView、内置浏览器）做了完整的降级处理

## 🎮 玩法

在棋盘上滑动（或按方向键）移动所有方块，相同的两个数字相撞时合并成一个，直到拼出 **2048**。

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | 方向键 或 `W` `A` `S` `D` | 在棋盘上滑动 |
| 鼠标移动 | 按住棋盘向任意方向拖动 | — |
| 撤销 | 「撤销」按钮 或 `Ctrl+Z` | 「撤销」按钮 |
| 重开 | 「新游戏」按钮 | 「新游戏」按钮 |

### 得分规则

- 合并得分 = 合并后的数值：`2+2→4` 得 **4** 分，`4+4→8` 得 **8** 分，`8+8→16` 得 **16** 分……
- 每次移动中，每个方块最多只参与一次合并（如 `2 2 2 2` 向左移动会得到 `4 4`，得 8 分）
- 无效移动（盘面没有变化）不会生成新方块，也不消耗撤销次数

### 胜利 / 失败

- 拼出 **2048** 时会出现胜利提示，点击浮层任意处可继续游戏
- 无空格且无法再合并时游戏结束，此时仍可「撤销」回上一步继续挑战，或点「新游戏」重开

## 🚀 运行

### 本地打开

直接双击 `index.html`，或用浏览器打开：

```
file:///<你的路径>/index.html
```

### 在微信里打开（重要）

微信的**「文件预览」和部分内置浏览器会拦截页面脚本**，此时页面会显示"正在加载…请用浏览器打开"的提示（这是环境限制，任何网页都无法绕过）：

- **电脑微信**：点击右上角「使用 Microsoft Edge 打开」
- **手机微信**：点右上角「···」→「用浏览器打开」
- **想直接在微信内游玩**：把 `index.html` 部署到任意静态托管（如 GitHub Pages、Gitee Pages 等），以**链接形式**分享——微信对网页链接的内置浏览器可正常运行脚本

## 🛠️ 技术说明

### 无限撤销的实现

- 维护一个**无数量上限的快照栈**，每个快照仅记录 `{ 棋盘值矩阵, 得分, 胜利/继续/结束标记 }`，数据量极小
- 仅在**有效移动前**压栈；撤销即弹栈并整体还原（棋盘、分数、浮层状态）
- 撤销后可继续正常游玩，历史记录保留，可反复撤销 / 重走

### 其他实现要点

- **移动合并**：按滑动方向从前方格开始遍历 + "最远空格"定位；`merged` 标记保证每个方块每次移动只合并一次
- **渲染**：方块 DOM 按稳定 id 复用，通过 `left/top` 过渡实现滑动；每次移动后统一"收尾"（落位、弹出、移除被吸收方块）
- **极速输入**：新输入到达时先立即结算上一次动画再计算，逻辑与动画解耦，连按不丢状态、不错乱
- **兼容性设计**：
  - 用纯 CSS `padding-top: 100%` 撑正方形（不依赖 `aspect-ratio`）
  - 定位用 `top/left/width/height`（不依赖 `inset`）
  - 字号用 JS 按棋盘宽度计算 CSS 变量（不依赖容器查询 `cqw`）
  - DOM 清理使用自写函数（不依赖 `replaceChildren` / `Element.remove`）
  - 输入 PointerEvent 优先，缺失时回退 `mouse` + `touch` 事件
  - 棋盘背景格为**静态 HTML**，即使脚本被拦截也能正常显示棋盘
